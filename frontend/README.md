# ChillBuddy - Your AI Study Bestie 🚀

ChillBuddy is a humorous, stress-busting AI voice assistant designed specifically for students. It's not just a study tool; it's a friend who helps you manage tasks, tells jokes when you're stressed, and keeps your student life on track.

## Features ✨

- **Humorous Persona**: Conversational, friendly, and always ready with a joke.
- **Stress Buster**: A dedicated button for instant relaxation and humor.
- **Task Mission Control**: Manage your assignments and study goals in the 'Missions' tab.
- **Multilingual Support**: Speaks English, Hindi, Telugu, and Tamil.
- **Voice-First**: Integrated with Edge TTS and Speech Recognition for a seamless hands-free experience.

## Tech Stack 🛠️

- **Frontend**: React + Vite + Lucide Icons
- **Backend**: FastAPI + Google Gemini AI (Flash)
- **Voice**: Edge TTS + Web Speech API

## Getting Started 🚀

### Backend
1. Go to `backend/`
2. Install dependencies: `pip install -r requirements.txt`
3. Add your `GEMINI_API_KEY` to `.env`
4. Run: `python main.py`

### Frontend
1. Go to `frontend/`
2. Install dependencies: `npm install`
3. Run: `npm run dev`
